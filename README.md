# FaceBaby Flutter

MVP em Flutter organizado para respeitar Page Objects/Screens.

## Estrutura

```txt
lib/
  main.dart
  app/face_baby_app.dart
  app/main_shell.dart
  controllers/ai_controller.dart
  models/baby.dart
  models/daily_summary.dart
  models/memory_item.dart
  services/mock_baby_service.dart
  pages/home_page.dart
  pages/quick_register_page.dart
  pages/report_page.dart
  pages/memories_page.dart
  pages/settings_page.dart
  widgets/ai_button.dart
  widgets/ai_overlay.dart
  widgets/card_box.dart
  widgets/stat_card.dart
  widgets/baby_card.dart
  widgets/event_tile.dart
  widgets/section_title.dart
  theme/app_theme.dart
```

## Rodar

```bash
flutter pub get
flutter run
```
